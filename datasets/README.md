# Datasets

## Purpose
This folder will be used for dataset planning and management once the vision and classification work begins.

## Guidance
- Keep raw data in [datasets/raw/](raw/) and avoid committing large or unreviewed captures unnecessarily
- Document dataset sources, labeling rules, and split decisions carefully
- Keep the dataset aligned with the actual prototype goal: sustainability sorting, not generic demo classification

## Current Status
- Dataset collection is planned for a later phase
- No dataset claims should be made until capture and labeling rules are defined
