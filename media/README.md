# Media

## Purpose
This folder is for photos, clips, and run captures that document the prototype as it evolves.

## Guidance
- Keep generated run captures in [media/runs/](runs/) and only retain assets that support a documented test or demo
- Prefer short, reviewable artifacts linked to engineering log entries or test notes
- Do not use media to imply a finished system when the project is still in prototype development

## Current Use
- Capture assembly state, test setups, and controlled demonstrations
- Support portfolio and documentation work with accurate visual evidence
