# Dashboard / Web Interface

## Purpose
This folder is reserved for a future operator-facing interface for status, diagnostics, and basic monitoring.

## Planned Responsibilities
- Show system state and key indicators
- Surface test notes or logged events
- Support observability without becoming a second control layer

## Current Status
- The dashboard is planned for a later integration phase
- The project should not depend on a UI before the embedded control and serial interfaces are stable

## Future Work
- Decide whether the dashboard is read-only or partially interactive
- Define the data it needs from the serial and logging layers
- Keep the interface minimal and appropriate for prototype debugging
