# Engineering Journal

## Purpose
This directory is for chronological engineering notes, test observations, and design decisions made during prototype development.

## What to Record
- Assembly progress and mechanical changes
- Calibration attempts and motion observations
- Power, wiring, and sensor troubleshooting
- Decisions, trade-offs, and unresolved questions
- Distributed control integration notes for the WiFi Rev2, Python bridge, and Uno R3 path

## Recommended Use
- Keep entries short, dated, and factual
- Record what changed before the result changed
- Note safety-related issues immediately
- Capture protocol decisions before they become hard to reverse
