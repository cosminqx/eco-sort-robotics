# Mounts

## Purpose
This folder is for mounting concepts, fixture notes, and support parts for the prototype bench.

## Scope
- Braccio arm base support concepts
- Sensor and indicator mounting ideas
- Cable-management and positioning notes

## Design Notes
- Mounts should support stability, repeatability, and easy reconfiguration
- Avoid overbuilding fixture hardware before the test requirements are clear
