# Mechanical Redesigns

## Purpose
This folder is reserved for iterative mechanical redesign ideas that improve reliability, handling, or usability.

## Scope
- Reliability-focused redesign notes
- Structural or fixture improvements discovered during testing
- Iterations that support future automation, sensor mounting, or safer motion

## Current Status
- Mechanical redesign work is exploratory and should remain grounded in observed prototype behavior
- Avoid speculative redesigns without a clear problem statement
